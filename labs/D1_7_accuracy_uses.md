# المختبر 1.7 · جدول الدقة والاستخدامات المسموح بها

دون مساعد ذكي: من مصفوفة جاهزة تحسب الدقة الكلية ودقة المستخدم ودقة المنتج لكل فئة، ثم تقرر لكل استخدام مقترح للخريطة هل يُسمح به.

اليوم 1 · الجلسة 7: الدقة لكل فئة والاستخدامات المسموح بها

### ستخرج من هذا المختبر بـ

- جدول الدقة: الدقة الكلية، ودقة المستخدم ودقة المنتج لكل فئة.
- قرار لكل استخدام من الاستخدامات الستة المقترحة للخريطة: مسموح أم غير مسموح، بسبب مكتوب.
- سطران لوكيل الهيئة سهم العطوي: ما الذي تصلح له الخريطة في الإقليم، وما الذي لا تصلح له.

> **دون مساعد ذكي.** فحص الدقة يتم دون ذكاء اصطناعي. جدول البيانات والآلة الحاسبة مسموحان.

## ما تحتاجه

[**start/confusion_matrix.csv**مصفوفة الالتباس جاهزة (نقطة البداية، لا تحتاج المختبر 1.6)](https://sdaiaacademy.github.io/use-sec-211/labs/files/start/confusion_matrix.csv) [**landcover/proposed_uses.csv**ستة استخدامات مقترحة، والفئة التي يعتمد عليها كل منها، والدقة التي يحتاجها](https://sdaiaacademy.github.io/use-sec-211/labs/files/landcover/proposed_uses.csv)

الخريطة ESA WorldCover 2021 (© ESA WorldCover project 2021، برخصة CC BY 4.0)، والمرجع من صور Sentinel-2 لعام 2021 كما في المختبر 1.6 (يحتوي على بيانات Copernicus Sentinel معدّلة، 2021). الاستخدامات المقترحة اصطناعية.

## الخطوات

### 1 · احسب الدقة الكلية 3 دقائق

مجموع القطر مقسومًا على مجموع النقاط.

### 2 · احسب دقة المستخدم لكل فئة 6 دقائق

دقة المستخدم: من النقاط التي تقول الخريطة إنها من الفئة، كم هي منها فعلًا؟ القطر على مجموع الصف. تجيب عمّن يفتح الخريطة ويثق بما يراه.

### 3 · احسب دقة المنتج لكل فئة 6 دقائق

دقة المنتج: من النقاط التي هي من الفئة فعلًا، كم رأتها الخريطة؟ القطر على مجموع العمود. تجيب عمّا تفوّته الخريطة.

| الفئة | دقة المستخدم | دقة المنتج |
| --- | --- | --- |
| مزروعة |  |  |
| جرداء |  |  |
| مبنية |  |  |
| عشبية |  |  |
| شجرية |  |  |

فئة لا نقطة مرجعية فيها: دقة المنتج لها غير محسوبة، فاكتب ذلك ولا تكتب صفرًا.

### 4 · قرر لكل استخدام مقترح 7 دقائق

لكل صف في `proposed_uses.csv`: قارن الدقة التي يحتاجها بما حسبته للفئة التي يعتمد عليها. وقاعدة الهيئة فوق كل رقم: القرار الذي يقع على مزارع واحد لا يُبنى على الخريطة وحدها، مهما بلغت دقتها.

### 5 · اكتب الاستخدامات المسموح بها 3 دقائق

سطران: ما تصلح له الخريطة هنا، وما لا تصلح له حتى تُحسَّن أو يُقاس بمرجع أفضل.

### ✱ تمرين إضافي

اختر استخدامًا غير مسموح، واكتب ما الذي يجعله مسموحًا: دمج فئتين، أو نقاط مرجعية أكثر، أو زيارة قبل القرار.

## أسئلة تحقق

1. ما الدقة الكلية، وكيف تقارن بالدقة الكلية التي ينشرها منتج الخريطة على مستوى العالم؟
2. لماذا تختلف دقة المستخدم عن دقة المنتج للفئة المزروعة؟
3. أي استخدام مرفوض مهما كانت الدقة، ولماذا؟
