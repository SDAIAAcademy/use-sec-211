# المختبر 2.1 · مهارة التنبؤ أمام المناخ المعتاد

تقارن تنبؤات حقيقية سابقة للتبخر نتح المرجعي بمهلة يوم ويومين وثلاثة بقيم ERA5 للأيام نفسها، وتحسب مهارة كل مهلة أمام المناخ المعتاد، وانحياز التنبؤ.

اليوم 2 · الجلسة 1: إعادة التحليل والتنبؤ ونماذج الطقس

### ستخرج من هذا المختبر بـ

- جدول فيه متوسط الخطأ المطلق لتنبؤ التبخر نتح المرجعي بمهلة يوم ويومين وثلاثة، وللمناخ المعتاد.
- مهارة كل مهلة أمام المناخ المعتاد، وانحياز التنبؤ.
- سطر واحد لمرشد الري شجاع السرحاني: هل يستحق التنبؤ أن يدخل قرار الري؟

## ما تحتاجه

[**weather/et0_forecasts_2024.csv**274 يومًا من فبراير إلى أكتوبر 2024: قيمة ERA5، والتنبؤ الصادر قبل يوم ويومين وثلاثة، والمناخ المعتاد لليوم](https://sdaiaacademy.github.io/use-sec-211/labs/files/weather/et0_forecasts_2024.csv) [**farm/farm_profile.txt**المزرعة الإرشادية التي ستستعمل التنبؤ في المختبرين 2.2 و2.3](https://sdaiaacademy.github.io/use-sec-211/labs/files/farm/farm_profile.txt)

البيانات حقيقية عامة لنقطة في الإقليم: التبخر نتح المرجعي اليومي (ET0، بالملم) من إعادة التحليل ERA5، والتنبؤات اليومية كما صدرت فعلًا قبل الموعد، وكلاهما من Open-Meteo.com برخصة CC BY 4.0؛ وأُعدّت قيم ERA5 باستعمال معلومات خدمة كوبرنيكوس لتغير المناخ (2024). المناخ المعتاد متوسط ERA5 لليوم نفسه من السنة في الأعوام 2000 إلى 2023، ضمن نافذة سبعة أيام قبله وبعده. الأداة جدول بيانات. المساعد الذكي مسموح بدور المعلّم: يشرح صيغة، ولا يحسب عنك.

## الخطوات

### 1 · افتح الملف واقرأ الأعمدة دقيقتان

الأعمدة: `C` قيمة ERA5 (ما حدث)، و`D` و`E` و`F` التنبؤ بمهلة يوم ويومين وثلاثة، و`G` المناخ المعتاد. الصفوف من 2 إلى 275. عمود الشهر `B` رقم من 2 إلى 10.

### 2 · احسب الخطأ المطلق لكل مهلة وللمناخ المعتاد 6 دقائق

أربعة أعمدة جديدة، ثم متوسط كل منها:

```
# ملف: et0_forecasts_2024.csv
H2  =ABS(D2-$C2)        lead 1
I2  =ABS(E2-$C2)        lead 2
J2  =ABS(F2-$C2)        lead 3
K2  =ABS(G2-$C2)        climatology
MAE =AVERAGE(H2:H275)   and the same for I, J, K
```

### 3 · احسب المهارة لكل مهلة 4 دقائق

المهارة نسبة ما يقلّه التنبؤ من خطأ المناخ المعتاد: صفر يعني أنه لا يزيد على المتوسط المعروف سلفًا، وواحد يعني تنبؤًا بلا خطأ.

```
# ملف: et0_forecasts_2024.csv
skill = 1 - MAE_forecast / MAE_climatology
```

| المهلة | متوسط الخطأ المطلق (ملم) | المهارة |
| --- | --- | --- |
| يوم |  |  |
| يومان |  |  |
| ثلاثة أيام |  |  |
| المناخ المعتاد |  | 0 |

### 4 · احسب الانحياز وقارن الربيع بالصيف 5 دقائق

الانحياز: هل يخطئ التنبؤ إلى جهة واحدة؟ ثم احسب مهارة مهلة اليوم في الربيع (الأشهر 3 إلى 5) وفي الصيف (6 إلى 8) وحدهما:

```
# ملف: et0_forecasts_2024.csv
bias          =AVERAGE(D2:D275)-AVERAGE(C2:C275)
MAE spring    =AVERAGEIFS(H2:H275,B2:B275,">=3",B2:B275,"<=5")
MAE summer    =AVERAGEIFS(H2:H275,B2:B275,">=6",B2:B275,"<=8")
```

كرر الصيغتين الأخيرتين على العمود `K`، ثم احسب المهارة لكل فصل.

### 5 · اكتب سطرًا لمرشد الري 3 دقائق

هل يغلب التنبؤ المناخ المعتاد؟ بكم، وفي أي فصل أقل؟ وماذا يعني الانحياز لمزرعة تروي على التنبؤ؟

### ✱ تمرين إضافي

قاعدة بسيطة أخرى: «غدًا مثل اليوم». ابنِ عمودًا يأخذ قيمة ERA5 للصف السابق، واحسب مهارة التنبؤ أمامها. هل ما زال التنبؤ يستحق؟

## أسئلة تحقق

1. ما مهارة التنبؤ بمهلة يوم أمام المناخ المعتاد؟ وكيف تتغير المهارة مع المهلة؟
2. هل يقدّر التنبؤ التبخر نتح بأقل أو بأكثر مما حدث؟ وكم في اليوم؟
3. لماذا نقيس المهارة أمام المناخ المعتاد لا أمام الصفر؟
